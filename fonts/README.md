# Czcionki innych alfabetów

`wayven-intl-<wersja>.ttf` (w przedwydaniu `radio-catalog`) to czcionka zapasowa Wayven OS dla pism, których nie ma w Montserrat: greka, chiński (uproszczony i tradycyjny), japoński, koreański, arabski, hebrajski, tajski, gruziński, ormiański, pisma indyjskie, etiopski, symbole i emoji. Złożona z czcionek [Noto](https://notofonts.github.io/) przez `tools/fonts/build_intl_font.py` w repozytorium projektu.
